Project Overview

The scope of this project is to simplify and streamline the integration of an LCD screen with the STM32 Nucleo-F446RE development board. Designed specifically as a 2nd-year engineering tool for Camosun College, this custom daughterboard (shield) eliminates the need for students to manually trace and wire individual connections between the screen and the microcontroller.

Instead, the LCD and Nucleo board work together seamlessly by plugging directly into a combination of a 14-pin header and a 28-pin header. This hardware design makes debugging and system state display highly convenient, letting students focus on programming and core system logic rather than wiring issues.

Key Improvements & Features

  • Direct Header Interface: Uses 14-pin and 28-pin header layouts to establish a secure, plug-and-play connection between the LCD and Nucleo board.
  • Multi-Protocol Swapping: A key iteration over previous generation boards is the implementation of a selectable path to easily swap between I2C and SPI display interfaces.
  • Improved Learning UX: Greatly reduces setup complexity for second-year students by removing standard jumper-wire debugging steps.
  • Robust Routing Schemas: Custom PCB trace routing engineered to fit the standard Nucleo form-factor seamlessly.
